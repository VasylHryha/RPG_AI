# Stage B development revision

Owner authorization: 2026-10-09 about 06:45 EEST, “ok lets do it, as you suggest”: diagnose existing paired fights, fire calibration and ten epochs, then full-fight DAgger and new looks. This is development evidence, not a registered GeoMind milestone, a scientific acceptance, or an RRG recursion result. HEAD baseline is a795ee4ffc641f0398c2131bd2d186297f6445e4. Stage A sources, training exports, raw files and its owner-stopped partial look remain unchanged.

Stage B is a separate directory and separately built/admitted native binary. It reuses the exact Stage A architecture and physical-tick inputs. Round 0 reuses the sealed whole-fight train/validation/test split, with ten epochs and four 90-tick stored-state windows per training fight. N2J0 is dropped to save one lane: both N2 variants lost all paired fights, but N2 made attacks whereas N2J0 did not; this is a cost decision and does not establish that J has no effect. N1, N1h, N1r and N2 run concurrently on measured performance cores, two threads per worker. There is no obsolete one-hour per-arm veto. Each invocation must fit the measured projection with 20% margin inside the live Claude-authored owner cap, maximum three hours. Reductions tighten deadlines; increases cannot extend an admitted invocation. Checkpoints resume only completed epochs with unchanged code/data/budget identity.

Fire loss uses ordinary categorical cross-entropy; the Stage A inverse-frequency hold bias is removed; release was absent from those labels, so its nominal weight did not itself affect the weighted-CE denominator. Final selected checkpoints receive one validation-only threshold per role on max(automatic, release) minus hold logits. Shared react/guard/body precedence remains authoritative. Threshold selection chooses the closest attainable oracle active count among unblocked rows, reports ties/residual rate error, precision and recall, and never reads outcome results. The same validation threshold is evaluated unchanged on the test split. The “active predictions / oracle active rows” number in Stage A is a count ratio, not recall.

The diagnosis also exposed target=None collapse despite available in-range enemies. Stage B balances None/nonzero target training examples per role from training labels only, with weights total/(2*class count). Movement and masked aim use SmoothL1 after converting both prediction and label to the existing geometry units of 100 pixels. This gives meaningful gradient to large geometric errors without hand-tuning per role. Fire and multiplier retain CE and MSE respectively. Seed 41001 and Adam 0.001 remain fixed; every supported fit declares ten epochs. Full-fight DAgger supplies targets and movement/aim labels in student-induced states; this is necessary because calibration alone cannot repair missing targets or movement drift.

One DAgger round is the default. Every arm plays two regular fights and twenty C3 fights (one per tactic), with fresh entropy, full duration up to normal termination or the 150-second bound. The student alone controls actions. O advances its own public-history controller on a cloned predecision world and supplies post-bridge, post-singleton-planner labels; no O command, RNG, private recurrent memory or state is transferred to the student. All physical ticks are recorded and labeled. The fixed four windows remain the fitting budget, with full-prefix memory replay. Each arm aggregates its own student occupancy with round 0; other arms' occupancy, validation/test fights and looks never enter training. Every round writes on-policy disagreement and measured full-fight cost, with original whole-fight validation/test retained. A second fresh round is supported after round-1 parity if residual disagreement warrants its measured cost; no third round.

New outcome seeds are paired across the four nets, O and T. Complete look 20 precedes look 50. Look 20 is a mechanism diagnostic; look 50 is a development outcome, with the existing >=2 deaths/kills harm threshold reported at 50. Every invocation records its actual completions and partial descriptive summaries, including refused/stopped/resumed invocations. Completing a command never supplies scientific acceptance. Collection/readout use the existing live LAB_CAP and process/RAM admission, and require measured full-duration disk projection plus a 5 decimal GB reserve. No completed Stage A fight is rerun.

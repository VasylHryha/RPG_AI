N1h's derived state is reconstructed by its own public-history controller, never copied from a teacher fighting elsewhere. It is an explicit privileged history-feature control, not a memoryless baseline or evidence of learned memory. Cached shared embeddings refresh at 5 Hz and immediately on entity removal. Fresh own physical features drive heads every physical tick, including release readiness; recurrence advances exactly once. Query identities are stable IDs, not slots. All friends and enemies remain visible, capped at 64 each. Shell/shot/field/cast banks have 64/64/32/32 slots, including all public own/enemy airborne shells and per-gun launch/splash constants. Overflow fails collection/inference rather than hiding a label-changing threat. Encoder computation is shared, no token self-attention or per-unit world re-encoding.

Training is float32, deterministic common initialization and window order, zero weight decay, matched epochs/windows/steps. Fight order and windows within each fight are shuffled identically across arms, with one measured reload per fight/epoch. Dense forward multiply/add FLOPs, encoder calls and phase RHS evaluations are counted; nonlinear/backward cost is not presented as a measured FLOP total. Default two epochs, four 90-tick windows/fight. A linear full-fight state refresh stores detached learned state and encoder caches at window boundaries; no teacher memory or quadratic prefix replay. Window losses retain readiness/release/reaction transitions and subsample other base decisions by four. Validation loss selects the earliest minimum epoch. Completed epoch checkpoints include optimizer and RNG state; unfinished epochs are discarded on resume. Outcomes record gradient steps, rows, CPU/wall/RSS, K and forcing movement from initialization. Network fights record phase rates, forcing magnitude and bounded spacing separately from shared safety behavior; no reset-based phase variation is present. These diagnostics do not establish causal necessity. State-refresh, validation and final diagnostics are included in the projection, with 20% margin. Twenty total timing steps at most, discarded as timing-only models. Each fit must project to <=1 hour; the concurrent job must fit the current owner TRAIN_CAP.

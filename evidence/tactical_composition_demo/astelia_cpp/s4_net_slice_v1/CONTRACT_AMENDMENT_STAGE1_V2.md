## Training and admission

R2D2 stored-state plus burn-in / truncated BPTT replaces the quadratic full-prefix-per-window clause. At each epoch start, N1r and N2 make exactly one full chronological no-grad pass under the current weights per training fight. Complete detached Replay state is stored at 90-tick boundaries and at max(0,boundary-30). Windows restore the latter, recompute 30 physical ticks under current weights with no gradient, detach, then retain the same 90-tick BPTT window. No arbitrary zero-state burn-in is permitted. The same method and refresh frequency apply to both recurrent arms. Stored states can be stale by up to one epoch of optimizer updates; burn-in mitigates rather than eliminates that approximation. At unchanged weights, a fixture compares full-prefix and restored outputs/phases/memory/features at absolute tolerance 1e-9, including launches/deaths at a boundary and within a window. Joint neighbor gradients remain attached.

Held-feature snapshots store their original float32 input values losslessly and restore float64; all learned/recurrent state remains float64. RSS is checked during refresh as well as optimizer steps. Float64, Adam learning rate .001, zero weight decay, finite checks, gradient norm cap 1, batch 4 and ten epochs remain. Weight-independent graph preprocessing and bounded four-fight tensor caching (features remain mmap-backed; only joint decision rows convert to float64) remove repeated graph construction and per-unit dict stacking in training. Decisions/rows/gradient steps match across arms. Shuffle seed is 41999+zero-based epoch for all arms. CPU threads 2, interop 1, workers 0; fits run sequentially under one repository job lock. No wall-time concurrency credit is assumed.

N1 seeds 41001,41101,41201 provide a descriptive noise yardstick. Primary N1 is always 41001, without selecting across seeds. N1r=41002 and N2=41003. Each N1 seed receives the identical matched budget and its own validation checkpoint selection. Training-only binary class weights up-weight whichever fire class is minority, ratio bounded [1,10] for each class, including minority holds. Apply identical weights in training and selection. Categorical losses/masks/head weights are unchanged. Aim top-1 is explicitly teacher-target-conditioned. Report move/aim non-zero top-1, per-class balanced accuracy, hold-when-ready recall and fire balanced accuracy.

## Interpretation, parity, future jobs

N2 has one shared bounded omega scalar, with individual variation supplied by observation-dependent forcing. Report learned K and omega, |forcing|, pre-reset phase velocity, order parameter and dispersion on validation. Fixed J=.5 remains an untrained motion prior; BC differences against a stateless teacher do not establish or refute RRG mechanisms. The three N1 seeds give descriptive ranges, not a significance claim.

Trained export parity streams 12-tick chunks through a persistent native Host/Python Replay, with arena GC at request boundaries and exact wait4 CPU/peak RSS checks on the native child. It uses whole test-fight sequences for all selected seeds/arms and every N2 intervention in float64 (atol=rtol=1e-9). These sequences supply recorded launch acknowledgements; they test inference/state parity. Separately, `stage1_logged_parity.verify` compares actual student Host logs with independently computed Python phases after actual launch resets, decision intents and drift, tracking native cast locks and deaths. DAgger/mechanism checks call this on each completed student fight before reporting/refitting. No new fight is launched for parity. A fight without launches/deaths cannot claim those events were covered; the receipts retain coverage counts.

Seven training visits cover all six cell/gun pairs, including D2-10; validation covers sparse+2 guns in round 1 and sparse+10 guns in round 2. Whole-fight split hashing and actual visitor context remain. All draws use v2 variation; all arms refit the same union including round 0.

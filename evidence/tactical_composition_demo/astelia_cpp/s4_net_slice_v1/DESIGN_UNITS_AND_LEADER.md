### Optional command boundary

New versioned command schema: presence and per-field masks; **focus pointer over the permitted enemy set**, focus-relative aim vector in px; in S3 only, `free / hold_start / start_at` with a bounded absolute game-time deadline; origin/expiry and gun/focus/plan identity as join metadata. Remove the unused volley-slot output. A plan identity joins logs and outstanding commands; it is not a network ID feature. There is no trained release-hold command. No shift head in the minimal build.

The focus point is the commanded enemy's public position at command origin. Store/cache the resulting **absolute** requested point once; do not keep adding offsets as the target moves. A teacher provenance record identifies the enemy whose led centre generated the cluster, or the explicit predicted centre used for a family. The label offset is `planner_point − commanded_enemy_position`, including lead and spread. The future wrapper must expose provenance from candidate creation; existing queue points alone do not always uniquely identify it. For a predicted centre, retain its source enemy reference plus the residual to its current public position. Per-gun focus may differ within a plan. None/invalid focus has an explicit mask, never a fabricated pointer.

On later decisions encode **`cached_absolute_aim − current_self_position` /100 px** in the unit command input, with current focus token/pointer, per-field validity, native target/aim-lock masks, pending-plan presence, command age, expiry−t and remaining start-wait budget. These are observable numerical inputs, not hidden identity/origin metadata. Reconstruct desired point from that current vector and self position. Candidate centres use the **current** resolved focus position; command radius uses `|cached_absolute_aim − current_focus_position|`. An origin-relative offset plus a moving focus must never create a new point. A valid refreshed aim command creates a new cached point once; an already locked native aim remains authoritative and its aim loss is masked.

A valid focus command is applied **before actual start and native target lock**. On each decision: advance unit state once → publish autonomous target/readiness/mode → leader readout → resolve focus on an unlocked gun → recompute target-dependent reach/opportunity and candidate support → conditional unit heads → simultaneous intents → native action. No second recurrent update. During winding the native target remains locked; matching-focus aim may be refreshed only until native aim lock. Incompatible late focus becomes empty with a reason; the leader cannot retarget a cast. Newly locked plan/focus and pending expiry are observable publications on following decisions.

At S2 start decisions the new script wrapper probes the copied planner using **currently startable candidate guns projected as ready in a public scratch world**, so focus/assignment can be decided before locking. This is a declared adaptation of the stateless spatial teacher, not an exact replay of ready-only v2. It uses current encoded public geometry, not hidden future readiness. After focus selection, actual startability is recomputed against that focus; infeasible assignments are logged, not fired. Preserve each feasible gun's start-plan aim through winding, subject to native locks and expiry. A new plan cannot replace locked focus. S1 checks the wrapper's legal coverage; if projecting current start opportunities loses useful focus/spread, revise before fitting. Plans with fewer than two feasible assigned guns, Singles and leftover Singles produce empty commands. No ensemble of independently chosen points is presented as the original joint plan.

Conditional commands request actions through learned unit heads; they never write native intents. Body/resource/reach/arena gates, reaction priority, consumed/no-launch acknowledgements and automatic release bound remain shared across U, U+P and U+R. Empty command reproduces U-alone. Expired/dead-target/incompatible commands fall back explicitly; malformed/nonfinite commands block the affected invocation. Neither deployed leader calls the script planner or search unless the arm is separately labelled search-assisted.

## 3. Unit labels and learnability

Use **one N2-derived unit arm U**, one fit seed initially, with geometry/mode state retained for direct publications. Set **J=0 at training and deployment** to remove the untrained J=.5 motion confound; A=B=.5 and movement share=.125 are shared. This is not unit-level RRG evidence. Trainable-J development and a trained J0 comparator are deferred until a specific motion claim needs them. This minimal choice supersedes revision 1's J auxiliary loss and twelve-unit-fit plan.

For S2 retain the permitted 1008-feature base view: self, up to 12 friend slots, 12 enemies and eight retained threats, masks and public own lifecycle fields. The unit oracle is reconstructed from the serialized encoded view at training precision. Its reaction/participation sees only represented units/threats. Enemy private state, teacher family/score, hidden future trajectories and tactical IDs are not features. The command branch additionally receives the permitted commanded focus token, masks and bounded aim/timing fields. Base U remains competent with command absent.

| Unit head | Autonomous label |
|---|---|
| target | Nearest supported living enemy, geometric tie order; pending native target kept when locked. |
| move | Represented-threat reaction first, otherwise engagement annulus and participation; nearest legal move candidate. |
| start | Current chosen-target reach, own body/resources/cooldown/prep and represented reaction, independent of friend readiness. |
| release | Own decision-tick projected readiness/opportunity and reaction, respecting native locks. |
| aim | Closest supported point to this gun's raw-public-velocity intercept on its chosen target; no joint queue or spread. |

Actual Game flight time is `distance(gun_position, aim_point)/lob`: [schema.cpp:36](schema.cpp) publishes distance-based landing time; [combat_rules.cpp:51–55](../src/native/combat_rules.cpp) uses it at launch. Define `tau0=|target−gun|/lob`, then **three fixed iterations** `q_k=target+velocity*tau_k`, `tau_(k+1)=|q_k−gun|/lob`; final `q=target+velocity*tau3`. Lob must be finite and positive. Record final fixed-point residual and compare with planner `.8*range/lob` baseline. Three iterations are an approximation, not an exact/optimal intercept; residual exceeding one-quarter splash radius on an unforced release-opportunity row returns to support/oracle revision. Do not add windup to release-row flight lead; start-row aim is provisional and refreshes before lock. No private smoothing or dodge RNG.

Keep 33 aim candidates, centre plus two 16-direction rings; radius is the shared public recipe `max(splash, |q−current_focus|, |cached_absolute_command_aim−current_focus|)` bounded by the **arena diagonal**, rather than a fixed 200 px truncation. Omit the command term when absent; absent command uses the unit's chosen target as focus. All terms are reconstructible from the encoded public/command context. Bound finite leader vectors with a radial map `Rmax*v/(1+|v|)`, `Rmax=arena diagonal`; physical arena/reach masks still apply. The larger envelope permits long focus lead/spread but does not guarantee precise quantization. Log requested, bounded, snapped and native-realized points, px errors and boundary cases. No scripted lead point replaces the network's chosen candidate. Before fitting, pilot support must keep unforced commanded/lead snap error within one-quarter splash on at least 95% of release opportunities per retained cell; otherwise the drafter revises support prospectively. Report excluded/undefined aim reasons without silently dropping hard rows.

Aim loss and primary aim accuracy/error are on **release-opportunity decision rows**, where a permission can first commit aim; other/provisional/locked rows have separate counts and no aim-loss mass. Separate singleton legal sets, centre-illegal rows and unforced nonzero aim. Compare centre and nearest-lead baselines. Start/release imbalance weights derive only from training rows and are bounded [1,10]; normalize each head by active-row count. Command-conditioned target/move/fire/aim labels are reconstructed after commanded-focus resolution, distinct from autonomous labels. Conditional target loss applies only before lock.

Use deterministic empty/present command augmentation with equal aggregate loss mass; both views retain original fight split and are not independent fights. S2 may teach unit **obedience** to synthetic legal start-veto/deadline commands using a deterministic conditional oracle, without claiming useful leader timing; P/R timing remains masked. This lets frozen U accept improved S3 timing commands. If obedience fails, repair U as the same arm before S3, with all contrasts sharing the resulting checkpoint.

Cheap decidability check: equal exact encoded inputs **including masks, resolved target, command and observable pending plan context** must yield equal active labels; count exact collisions/conflicts per head/split. Require zero exact conflicts. One diagnostic bin width **.02 in normalized continuous units**, exact categorical/boolean bins, with occupancy and conflict counts; no three-width entropy battery. Sparse/no collisions are not proof. Restrict oracle dependencies and check wire permutations; sample checks detect errors, not universal decidability.

## 4. Two leaders, one child checkpoint

Both leaders read identical masked direct gun publications: position/size/velocity/HP, cooldown/prep/windup/time_rate/body/resources, lob/splash, start/release opportunity, provisional and locked targets, pending accepted plan/expiry, and direct mode/port validity. They see the same public enemies, own non-gun scaffold tokens and public own/enemy threats. No descendant private state, branch result or teacher score is a prediction feature. S2 limits: ten controlled guns, twelve total own units including scaffolds, twelve enemies and 64 raw threats. These are **slice bounds**, not full-army bounds.

Use deterministic canonical **insertion order by public geometry with stable join-key tie routing**, preserve planner-bound `q.gun.slot`, then scatter labels to gun identities. IDs are not numeric features or oscillator initializers. Assert/count exact physically indistinguishable ties; mask identity-specific assignment supervision for those ties and report their rate. No Hungarian matching or complete-token sort machinery. Permuting wire order must permute outputs without changing physical commands for non-ties; tied rows cannot support assignment attribution.

P: two masked 64-wide set-attention blocks (four heads), invariant pooling and shared per-gun readout; bounded **eight-coordinate recurrent group memory**. R: identical observation encoder, pooling and command support, but **replaces P's recurrent memory**, rather than retaining it, with persistent parent resonator state: Phi, composed direct mode/geometry/ports and validity. Phi persists; composed quantities refresh from direct publications, not extra learned recurrent memory. Match learned parameter counts within 10% by readout width, fix widths before fitting, report actual work/time/RSS. Same rows, steps, seed index and selection rule; no best-seed picking. Equal parameter count is not equal FLOPs.

U publishes live child phases theta_i. P/R receive identical sin/cos summaries, no hidden latent array. Radius-squared weights `w_i=radius_i^2/sum radius_j^2` give `X=sum w_i p_i`, `L=sqrt(sum w_i(|p_i−X|^2+radius_i^2))`, `m=sum w_i exp(i theta_i)`, dispersion, size-weighted natural rate, readiness/ports and S. R owns persistent Phi initialized to arg(m) when coherent, otherwise zero plus ambiguity flag; no ID-based phase. Proposed bounded dynamics: `dPhi/dt=Omega+F(geometry,public_context)+K_up*Im(m*exp(-iPhi))`, Omega inherited from size-weighted child natural rates within the child's ±2 rad/s bound, F within ±1 rad/s, K_up within [0,2] rad/s. R readouts consume Phi sin/cos and the same tokens; commands change unit actions/geometry, which changes publications and forcing. Same held-input physical-tick integration procedure at both levels, simultaneous read/commit; derive/check combined numerical bound before implementation execution. Invalid parent produces empty commands; no unit is frozen/deleted.

This is a local **geometry ↔ mode ↔ command ↔ geometry candidate loop**, with lawful direct-child upward publications and bounded downward ports. Assigned battery membership is not spontaneous formation. Upper publication is `{X,L,M_eff,ports,S,digest}`; descendant details remain owner/evaluator-side, outside any upper prediction API. Full-versus-coarse capacities/rates need qualification before next-level prediction/dynamics claims. S2 exercises wiring only. S3 must exercise mode-dependent timing and geometry-dependent mode evolution with separate causal interventions before attributing task benefit. Full `B_n → R_n → B_(n+1)` causal background recursion, H-U/H-COMP/H-BG/H-PS and source recursion remain NOT_TESTED.

### S3 — timing/state coordination and search-guided Expert Iteration

This is the **decision-0036 stage-2 route** and eventual RRG-vs-plain coordination test. Timing acts on **start decisions**: `hold_start` vetoes new windup for this decision; `start_at` requests start at first decision opportunity at/after absolute game-time deadline, within maximum **1 s start-delay horizon**. Deadline/focus/accepted plan persist as explicit publications; expiry or safety veto gives autonomous fallback and reason. Waiting cannot cancel a started cast, refund resources or hold release past native six-tick bound. Release remains U's readiness policy. “Together” means coordinated arrival/release windows under native mechanics, not identical launches. Measure start/release/landing spread separately.

The **cumulative** wait begins at the first eligible start opportunity of the current attempt, with an observable origin and remaining budget. Repeated `hold_start`, focus changes or replacement plan IDs cannot reset that origin or extend its deadline. At origin+1 s, the timing veto is removed and U's autonomous start permission resumes subject to ordinary reaction/resource/body/reach/native gates; no forced shot. Clear the wait episode only on actual native start/consumption, death, or a logged loss of **autonomous public opportunity/safety eligibility**. Leader-induced focus/reach changes, expired deadlines or malformed/unsupported commands cannot clear the episode; a new episode cannot be created merely by the leader renaming its plan. Use this same rule for teacher branches and all deployed arms.

**Minimal engine search teacher:** at multi-gun start decision, enumerate finite slate: autonomous immediate starts; one current-focus planner assignment; one alternate cluster/assignment from planner shortlist. For each nonempty assignment compare immediate starts, one-decision delay, synchronized completion/landing deadlines (quantized to six-tick cadence, clipped to 1 s). Include coming guns by **public own** cooldown/prep/time_rate, unlike v2. Cap at **12 root joint-command candidates**, depth two group decisions, beam width two (**<=36 command branch expansions**). Advance **every candidate to the same root time t+3 s**, independent of its wait, assignment or volley landing; a battle ending earlier has absorbing terminal HP state and zero later increments. Log unresolved volleys at that common cutoff. Receding-horizon timing can maintain/revise observable commitments; rejected starts and invalid/dead guns obey native mechanics. Candidate generation/bounds fixed before labels. If >5% of search decisions have relevant volleys beyond horizon, revise horizon/budget before collecting labels.

Build branches from the **same serialized public group view**, neutral hidden-state defaults as public projection. Do not copy living-world opponent private state, future RNG or teacher history. Candidate branches share prospectively fixed opponent policy/neutral random streams, inaccessible to learner. This is model-based public-state look-ahead, not omniscient play. Inputs include observable outstanding plans and permitted chronological state; conflict checks condition on context. Equal inputs with deterministic search/tie order yield equal labels. Evaluate in real engine on fresh paired battles; model mismatch is a limitation.

Terminal score starts with `enemy HP damage − own HP damage`, divided by 200 HP; ties prefer less waiting then canonical candidate order. Record both axes and friendly splash separately. **First-cycle shared teacher:** freeze the S2 plain leader as the common spatial policy prior, with timing alternatives uniformly ordered; terminal value is **zero for both learners**. Its canonical public-history replay state is derived once and recorded as label context, never copied from private opponent/teacher history. Evaluate the same finite candidate slate under the same ordering, projection, streams and score, then reuse the same improved labels for P/R. Priors rank exploration, but empty/immediate baseline is always evaluated. Commands in branches pass through **the frozen U conditional readout and the same cache, safety, lock and opportunity gates as deployment**; never call native `launch()` to bypass the unit. Improved candidate must score at least as well as immediate baseline; log ties/improvement/start-delay coverage. Teacher objective does not replace owner's outcome metrics.

Train a **value head on each leader** for later Expert Iteration: at the common root t+3 s cutoff, add one fixed **1 s continuation to root t+4 s** under the common frozen S2 U+P controller, autonomous timing, fixed scaffold/opponent policy and the same neutral branch streams. Its target is the additional `(enemy HP damage − own HP damage)/200 HP` accrued during that second, zero discount; use the same absorbing terminal treatment if the battle ends. Total label simulation is bounded by 3 s search + 1 s tail; tail cannot generate extra search expansions. Record unresolved shells at search cutoff and tail cutoff, early terminal coverage and actual total costs. Value loss sees only training/validation continuations, never outcome fights. Both leaders get identical targets and loss weights. First-cycle policy improvement does not use their newly fitted value heads. A later approved cycle freezes **one common** prior/value (the previous plain checkpoint, chosen by rule before outcomes) for both sets of labels; record that teaching bias. Model-specific search-guided P/R priors/values are separately named future **search-assisted** comparators with matched budgets, not the common-label network-only comparison.

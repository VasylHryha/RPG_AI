### Optional command boundary

New versioned command schema: presence and per-field masks; **focus pointer over the permitted enemy set**, a spread-shape vector in px relative to the focus's led centre; in S3 only, `free / hold_start / start_at` with a bounded absolute game-time deadline; origin/expiry and gun/focus/plan identity as join metadata. Remove the unused volley-slot output. A plan identity joins logs and outstanding commands; it is not a network ID feature. There is no trained release-hold command. No shift head in the minimal build.

At start, the command fixes focus, gun assignment and spread shape. A teacher provenance record identifies the enemy whose led centre generated the cluster, or the explicit predicted centre used for a family. The shape label is `planner_point − planner_provenance_led_centre`; it includes the cluster residual/spread but excludes that centre's flight lead. The wrapper must expose that centre and its source enemy reference when it creates candidates; a queue point alone may not identify them. Each gun may have a different focus. None/invalid focus has an explicit mask, never a fabricated pointer. Cache a provisional absolute point at start, together with the shape vector and a `release_refresh_done` flag initially false.

At the **first release-opportunity decision**, before native aim lock, perform exactly one declared refresh for each feasible commanded cast. Recompute its locked focus's led centre from current public position/velocity with §3's three actual-distance fixed-point iterations. Add the stored shape vector and cache the resulting absolute requested point once; set `release_refresh_done=true`. This is the sole recomposition, even if U declines release on that row. It does not refresh focus, extend expiry, change assignment or drift continuously. Later decisions reuse this cached point. If the first opportunity is already aim-locked, the focus is dead/invalid, or the command has expired, log the reason and use the lawful autonomous/native fallback. An active cast's shape cannot be replaced by a subsequent plan. The same wrapper applies to teacher labels, conditional U, P/R and search branches. The refresh is public command-coordinate construction; learned U still selects and executes the supported aim candidate.

On later decisions encode **`cached_absolute_aim − current_self_position` /100 px** in the unit command input, with the stored shape /100 px, `release_refresh_done`, current focus token/pointer, per-field validity, native target/aim-lock masks, pending-plan presence, command age, expiry−t and remaining start-wait budget. These are observable numerical inputs, not hidden identity/origin metadata. Reconstruct the desired point from that current vector and self position. Candidate centres use the **current** resolved focus position; command radius uses `|cached_absolute_aim − current_focus_position|`. Outside the one declared first-release refresh, a moving focus must never recompose the cached point. An already locked native aim remains authoritative and its aim loss is masked.

A valid focus command is applied **before actual start and native target lock**. On each decision: advance unit state once → publish autonomous target/readiness/mode → leader readout → resolve focus on an unlocked gun → recompute target-dependent reach/opportunity → perform the one first-release refresh if due → recompute candidate support → conditional unit heads → simultaneous intents → native action. No second recurrent update. During winding the native target remains locked. Incompatible late focus becomes empty with a reason; the leader cannot retarget a cast. Newly locked plan/focus and pending expiry are observable publications on following decisions.

At S2 start decisions the new script wrapper probes the copied planner using **currently startable candidate guns projected as ready in a public scratch world**, so focus/assignment can be decided before locking. This is a declared adaptation of the stateless spatial teacher, not an exact replay of ready-only v2. It uses current encoded public geometry, not hidden future readiness. After focus selection, actual startability is recomputed against that focus; infeasible assignments are logged, not fired. Preserve each feasible gun's focus and shape through winding, then perform the single first-release aim refresh above, subject to native locks and expiry. A new plan cannot replace locked focus. S1 checks legal coverage and moving-target miss before fitting. Plans with fewer than two feasible assigned guns, Singles and leftover Singles produce empty commands. No ensemble of independently chosen points is presented as the original joint plan.

Conditional commands request actions through learned unit heads; they never write native intents. Body/resource/reach/arena gates, reaction priority, consumed/no-launch acknowledgements and automatic release bound remain shared across U, U+P and U+R. Empty command reproduces U-alone. Expired/dead-target/incompatible commands fall back explicitly; malformed/nonfinite commands block the affected invocation. Neither deployed leader calls the script planner or search unless the arm is separately labelled search-assisted.

## 3. Unit labels and learnability

Use **one N2-derived unit arm U**, one fit seed initially, with geometry/mode state retained for direct publications. Set **J=0 at training and deployment** to remove the untrained J=.5 motion confound; A=B=.5 and movement share=.125 are shared. This is not unit-level RRG evidence. Trainable-J development and a trained J0 comparator are deferred until a specific motion claim needs them. This minimal choice supersedes revision 1's J auxiliary loss and twelve-unit-fit plan.

For S2 retain the permitted 1008-feature base view: self, up to 12 friend slots, 12 enemies and eight retained threats, masks and public own lifecycle fields. The unit oracle is reconstructed from the serialized encoded view at training precision. Its reaction/participation sees only represented units/threats. Enemy private state, teacher family/score, hidden future trajectories and tactical IDs are not features. The command branch additionally receives the permitted commanded focus token, masks and bounded aim/timing fields. Base U remains competent with command absent.

| Unit head | Autonomous label |
|---|---|
| target | Nearest supported living enemy, geometric tie order; pending native target kept when locked. |
| move | Represented-threat reaction first, otherwise engagement annulus and participation; nearest legal move candidate. |
| start | Current chosen-target reach, own body/resources/cooldown/prep and represented reaction, independent of friend readiness. |
| release | Own decision-tick projected readiness/opportunity and reaction, respecting native locks. |
| aim | Closest supported point to this gun's raw-public-velocity intercept on its chosen target; no joint queue or spread. |

Actual Game flight time is `distance(gun_position, aim_point)/lob`: [schema.cpp:36](schema.cpp) publishes distance-based landing time; [combat_rules.cpp:51–55](../src/native/combat_rules.cpp) uses it at launch. Define `tau0=|target−gun|/lob`, then **three fixed iterations** `q_k=target+velocity*tau_k`, `tau_(k+1)=|q_k−gun|/lob`; final `q=target+velocity*tau3`. Lob must be finite and positive. Record final fixed-point residual and compare with planner `.8*range/lob` baseline. Three iterations are an approximation, not an exact/optimal intercept; residual exceeding one-quarter splash radius on an unforced release-opportunity row returns to support/oracle revision. Do not add windup to release-row flight lead; start-row aim is provisional and refreshes before lock. No private smoothing or dodge RNG.

Keep 33 aim candidates, centre plus two 16-direction rings; radius is the shared public recipe `max(splash, |q−current_focus|, |cached_absolute_command_aim−current_focus|)` bounded by the **arena diagonal**, rather than a fixed 200 px truncation. Omit the command term when absent; absent command uses the unit's chosen target as focus. All terms are reconstructible from the encoded public/command context. Bound finite leader vectors with a radial map `Rmax*v/(1+|v|)`, `Rmax=arena diagonal`; physical arena/reach masks still apply. The larger envelope permits long focus lead/spread but does not guarantee precise quantization. Log requested, bounded, snapped and native-realized points, px errors and boundary cases. No scripted lead point replaces the network's chosen candidate. Before fitting, pilot support must keep unforced commanded/lead snap error within one-quarter splash on at least 95% of release opportunities per retained cell; otherwise the drafter revises support prospectively. Report excluded/undefined aim reasons without silently dropping hard rows.

Aim loss and primary aim accuracy/error are on **release-opportunity decision rows**, where a permission can first commit aim; other/provisional/locked rows have separate counts and no aim-loss mass. Separate singleton legal sets, centre-illegal rows and unforced nonzero aim. Compare centre and nearest-lead baselines. Start/release imbalance weights derive only from training rows and are bounded [1,10]; normalize each head by active-row count. Command-conditioned target/move/fire/aim labels are reconstructed after commanded-focus resolution, distinct from autonomous labels. Conditional target loss applies only before lock.

Use deterministic empty/present command augmentation with equal aggregate loss mass; both views retain original fight split and are not independent fights. S2 may teach unit **obedience** to synthetic legal start-veto/deadline commands using a deterministic conditional oracle, without claiming useful leader timing; P/R timing remains masked. This lets frozen U accept improved S3 timing commands. If obedience fails, repair U as the same arm before S3, with all contrasts sharing the resulting checkpoint.

Cheap decidability check for S2 unit/spatial labels: equal exact encoded inputs **including masks, resolved target, command and observable pending plan context** must yield equal active labels; count exact collisions/conflicts per head/split. Require zero exact conflicts. One diagnostic bin width **.02 in normalized continuous units**, exact categorical/boolean bins, with occupancy and conflict counts; no three-width entropy battery. Sparse/no collisions are not proof. Restrict oracle dependencies and check wire permutations; sample checks detect errors, not universal decidability. S3a applies this check with its flagged privileged channel. S3b replaces snapshot zero-conflict requirements for timing labels with bounded-public-history recoverability and P0/P checks (§5); differing hidden readiness at an equal public snapshot is intentional there.

## 4. Two leaders, one child checkpoint

Both leaders read identical masked direct gun publications: position/size/velocity/HP, cooldown/prep/windup/time_rate/body/resources, lob/splash, start/release opportunity, provisional and locked targets, pending accepted plan/expiry, and direct mode/port validity. They see the same public enemies, own non-gun scaffold tokens and public own/enemy threats. No descendant private state, branch result or teacher score is a prediction feature. The sole opponent-state exception is the explicit, flagged S3a leader input in §5; U and S2/S3b leader inputs remain public. S2 limits: ten controlled guns, twelve total own units including scaffolds, twelve enemies and 64 raw threats. These are **slice bounds**, not full-army bounds.

Use deterministic canonical **insertion order by public geometry with stable join-key tie routing**, preserve planner-bound `q.gun.slot`, then scatter labels to gun identities. IDs are not numeric features or oscillator initializers. Assert/count exact physically indistinguishable ties; mask identity-specific assignment supervision for those ties and report their rate. No Hungarian matching or complete-token sort machinery. Permuting wire order must permute outputs without changing physical commands for non-ties; tied rows cannot support assignment attribution.

P: two masked 64-wide set-attention blocks (four heads), invariant pooling and shared per-gun readout; bounded **eight-coordinate recurrent group memory**. R: identical observation encoder, pooling and command support, but **replaces P's recurrent memory**, rather than retaining it, with persistent parent resonator state: Phi, composed direct mode/geometry/ports and validity. Phi persists; composed quantities refresh from direct publications, not extra learned recurrent memory. Match learned parameter counts within 10% by readout width, fix widths before fitting, report actual work/time/RSS. Same rows, steps, seed index and selection rule; no best-seed picking. Equal parameter count is not equal FLOPs.

U publishes live child phases theta_i. P/R receive identical sin/cos summaries, no hidden latent array. Radius-squared weights `w_i=radius_i^2/sum radius_j^2` give `X=sum w_i p_i`, `L=sqrt(sum w_i(|p_i−X|^2+radius_i^2))`, `m=sum w_i exp(i theta_i)`, dispersion, size-weighted natural rate, readiness/ports and S. R owns persistent Phi initialized to arg(m) when coherent, otherwise zero plus ambiguity flag; no ID-based phase. Proposed bounded dynamics: `dPhi/dt=Omega+F(geometry,public_context)+K_up*Im(m*exp(-iPhi))`, Omega inherited from size-weighted child natural rates within the child's ±2 rad/s bound, F within ±1 rad/s, K_up within [0,2] rad/s. R readouts consume Phi sin/cos and the same tokens; commands change unit actions/geometry, which changes publications and forcing. Same held-input physical-tick integration procedure at both levels, simultaneous read/commit; derive/check combined numerical bound before implementation execution. Invalid parent produces empty commands; no unit is frozen/deleted.

This is a local **geometry ↔ mode ↔ command ↔ geometry candidate loop**, with lawful direct-child upward publications and bounded downward ports. Assigned battery membership is not spontaneous formation. Upper publication is `{X,L,M_eff,ports,S,digest}`; descendant details remain owner/evaluator-side, outside any upper prediction API. Full-versus-coarse capacities/rates need qualification before next-level prediction/dynamics claims. S2 exercises wiring only. S3a checks privileged timing imitation and cannot establish RRG state. Only S3b cells passing the trained P0/P memory-necessity gate may support a stateful R/P reading, and mode-dependent timing and geometry-dependent mode evolution still require causal interventions. Full `B_n → R_n → B_(n+1)` causal background recursion, H-U/H-COMP/H-BG/H-PS and source recursion remain NOT_TESTED.

### S1 — small script-only contestedness and wrapper pilot

Use separate pilot entropy, excluded from later training, validation and outcome pools. Start with D2-2 and D2-10. Add moving/dodging-enemy two- and ten-gun cells if needed. Start with at most four cells and ten paired pilot battles per cell. Extend a cell to twenty pairs only to resolve wrapper coverage or detectability. On moving cells, report **wrapper-versus-autonomous landing miss** for each root-commanded shell. At its first release opportunity, compute both the refreshed commanded point and the same gun's autonomous actual-distance intercept for the **same locked focus and release instant**. For its realized flight time, compare the requested and native-snapped points with that focus's observed position at landing; compute the autonomous counterfactual's own flight time and observed focus position at its corresponding landing time. These shadow points do not alter the fight. Report paired miss differences in px, mean/median/p90, splash-normalized differences, counts and missing/terminal reasons. Also report a shape-subtracted miss (`point − stored shape` versus the corresponding observed focus position) so deliberate spread can be distinguished from stale lead. The raw commanded-point miss is still the conservative admission metric; an intentional spread that fails it needs a prospective wrapper revision, never a post-outcome exemption. A cell needs at least twenty matched, finite release/landing observations across at least five fights; insufficient coverage is unresolved.

Choose at most two tactical cells using pilot evidence, then **freeze cell definitions, opponent parameters, allocation, useful effects, harm tolerances and final pair count before requesting outcome entropy**. Each retained cell needs multi-gun commands on at least 5% of eligible multi-gun decisions, changed commanded assignment and physical shell/impact patterns on at least 5% of those decisions, and an informative primary axis. An axis is informative if neither teacher arm places more than 90% of pilot fights at that axis's physical floor or ceiling, and its uncertainty-inflated planning MDE at the chosen 100 or 200 pairs is no greater than its declared useful effect. A nonzero chaotic trajectory difference alone does not qualify. Record signed pilot effects; cell admission does not establish positive utility. D2-10 death saturation excludes survival as its primary axis. D1-10 remains a time-to-clear diagnostic, and sparse D1-1/D2-1 remain imitation/sanity coverage. No pilot fight enters outcomes.

For every cell and axis, report the paired spread, pilot mean difference and MDE at **both 100 and 200 pairs**. For additive axes, use `d_i = axis(T-unit+wrapper)_i − axis(T-unit-alone)_i` and the sample paired SD `s_d`. Because ten to twenty pairs give uncertain spread, also report `s_up = s_d * sqrt((m−1)/chi_square_quantile(.05,m−1))`, where m is the pilot pair count. This is a one-sided 95% upper SD calculation **under a Gaussian paired-difference approximation**, not a distribution-free bound for discrete deaths, sparse kills, mixed damage or exchange pseudovalues. The development planning estimate is `MDE_N = (z_.975 + z_.80) * s_up / sqrt(N) ≈ 2.80*s_up/sqrt(N)`, in the axis's units (two-sided alpha .05, power .80, normal approximation). Report ordinary `s_d`-based MDE alongside this uncertainty-inflated planning estimate; neither guarantees power, especially under a changed student policy. Constant, floor/ceiling-saturated or missing axes are marked unusable, not assigned MDE zero. For kills per own death, keep the ratio of totals: report both arm denominators and estimate paired spread with delete-one-pair jackknife pseudovalues of the **difference of those ratios**, never ratios per fight. A zero denominator or fewer than five own deaths in either pilot arm makes exchange detectability unresolved. Censored clear-time has no additive MDE unless all pilot clears are observed; otherwise it stays diagnostic.

The default useful-effect ledger below is a **declared design threshold**, not a measurement or a universal full-army number. S1 writes the actual roster/HP-derived numbers for each cell and chooses one primary axis before outcomes. It may amend these defaults only prospectively with a documented cause before outcome allocation. Other axes remain reported and serve as harm checks; choosing a new primary after outcomes requires new cells/entropy.

| Axis | Declared useful benefit per cell | Declared harm tolerance per cell |
|---|---|---|
| Own deaths/fight | Save 0.10 × initial own roster; 0.2 for two guns, 1.0 for ten guns if no scaffolds | Increase at most 0.05 × own roster |
| Enemy kills/fight | Gain 0.10 × initial enemy roster | Lose at most 0.05 × enemy roster |
| Enemy HP damage/fight | Gain 0.10 × initial enemy total maxHP | Lose at most 0.05 × enemy total maxHP |
| Exchange ratio of totals | Gain 0.10 kills per own death, with nonzero qualifying denominators | Lose at most 0.05 kills per own death |
| Clear time, diagnostic only | Reduce 0.10 × declared fight horizon in seconds | Report censoring and death-before-clear; no tactical promotion from this axis |

A useful development result at the sealed final N means the paired primary benefit estimate is at least its useful threshold and its paired 95% CI excludes zero. Both survival and enemy-damage harm must have one-sided 95% bounds within the sealed harm tolerances. Seal paired t intervals with N−1 degrees of freedom for additive fight axes and delete-one-pair jackknife/t intervals for ratio-of-totals contrasts before outcomes; these are approximate inference methods. Fewer than five nonzero pair differences or zero estimated variance makes **primary benefit inference** unestimable, with the raw difference still reported descriptively. Exchange also requires at least five own deaths in each arm and finite delete-one-pair denominators. For sparse/zero-variance additive harm differences, use a predeclared one-sided exact binomial upper bound on the fraction of harmed pairs, multiplied by the cell's sealed maximum possible positive per-fight harm (own roster for deaths; enemy HP pool for damage in the initial no-healing cells). This bounds harm without declaring an all-zero sample to be certain safety. If a finite physical bound is unavailable, that harm check is unestimable. If harm bounds cannot be estimated or cross the tolerance, the result is inconclusive/tradeoff, not useful. Keep all-draw accounting and report all axes, including saturated ones. A claimed result additionally seals the contrast family and uses multiplicity-adjusted intervals and the corresponding MDE (`z_(1−.05/(2K)) + z_.80` for K declared tests); it does not reuse an unadjusted development look as confirmation. After fitting, the separate ten-to-twenty-pair mechanism sample reports paired spread/MDE for each actual student contrast too, before that contrast's fresh outcome entropy. If it predicts MDE above the sealed useful effect even at 200 pairs, park the contrast or request a prospective revised task; never lower its threshold after viewing outcomes.

# Field ownership for constant/table callback readers

The generated `native_feature_ledger.json` inventories 159 named function readers separately from constant-table callbacks. Its `field_access_lifetime_map` retains the source reader labels; 38 entries read only table callbacks or export glue and therefore have no named-function module in that automated projection. They are resolved here, with explicit storage/lifetime policies. This is an inventory projection limitation, not 38 missing simulation functions. The compiled callback and source-derived catalog checks are in `native_formation_contract.cpp`, `native_api_contract.cpp` and `test_native_api.py`.

| Source field names | Native owner/caller | Authority and branch lifetime |
|---|---|---|
| `FormationSim`, `exports` | Browser export binding; native entry points in src/native/api.h and src/native/host.cpp | Browser global/module binding is excluded; no mutable simulation authority to clone. |
| `ceil`, `frontSpacing`, `rangedRanks`, `rankSpacing`, `rearGap`, `screenGap` | SHAPES callbacks implemented by src/native/formation.cpp and immutable formation_types.h settings | Stack-local shape construction reads immutable formation parameters; derived slots are rebuilt, while current unit/pack formation authority is copied. |
| `def`, `parse`, `skittish` | Source skill/kind/table initialization; src/native/config_codec.cpp, config.h, world.cpp and compiled catalog_data.h | Parse/default resolution happens at configuration creation; immutable config is shared. Unit dodge/cast/energy state derived from it is world-owned and cloned. |
| `approach`, `esoft`, `ourArt`, `ourCount`, `ourMelee`, `ourShoot`, `outranged`, `recentTaken`, `shootRush`, `sieging`, `theirArt`, `theirCount`, `theirMelee`, `theirShoot` | RULES/STORM_RULES/WOLF_RULES predicates; src/native/commander.cpp and formation_types.h | ReadEnemy snapshots are stack-local derived observations; pack/tactic/history authority remains world-local and is copied. Immutable rule predicates carry no mutable capture into a child. |
| `axis`, `ec`, `finishing`, `fixlob`, `ids`, `oc`, `pack`, `ratio0`, `startMelee`, `startTheirs`, `tchain`, `theirs`, `wallDist` | COMBOS/goal/phase callbacks; src/native/director.cpp, formation.cpp and formation_types.h | Bound generation references, role assignments, director/phase timestamps and initial counts are world-owned authority and cloned. Observation/selection/projection temporaries are rebuilt per call. Typed goal predicates and combo definitions are compiled functions without world-capturing closures. |

Every empty automated named-reader projection is covered above; the remaining fields map through their actual named source functions in the generated ledger. JSON boundary fields are read once; no property dictionary is used for native unit, pack or branch state. Browser binding is explicitly excluded. Compiled catalog callback descriptors expose names/paths; execution dispatches to native shape/rule/director implementations. They are not interpreted JS callbacks.

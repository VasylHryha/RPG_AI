## 3. Arm B: prospective background and model

The background is an **active bath**, not a parent label or a published node.
B's state is the positions, unwrapped phases, intrinsic rates and current neighbor
topology of 24 bath elements. Initial bath positions are uniform in a disk radius 3
centred at (4,0); phases uniform; rates uniform in [-.5,.5]. A source cohort has
24 initially unformed elements in a disk radius 3 centred at (0,0), uniform phases,
and identical intrinsic rate zero. These are apparatus populations, not planted
resonator memberships. All initial randomness is paired across conditions.

This bath/source layout and the later-source layout are fixed before outcomes.
No harvested C4 resonator is inserted in B. The detector discovers memberships
from observables and never sees source/bath tags or expected groupings. Restricting
the evaluator's source attribution to the prescribed cohort does not supply labels
to formation detection. Cross-cohort formations are reported as such and cannot
silently substitute for the registered source.

### Controlled causal path

Use a new R3-owned directed adapter of C4's force/phase terms. Internal bath and
internal source dynamics retain the C4 terms and nearest-eight/radius-three rule.
External contributions are computed in a separate directed channel, using up to
eight nearest external elements within radius 3, mean over that channel's actual
neighbors; a zero-neighbor channel contributes zero. Internal and external means
are summed. External phase coupling uses K=1 and exp(-r²); external geometry uses
A=1, B=1, J=.8, eps=10^-6. No rates, couplings or capture radii are fit per level.
This is a new model projection: it is not the frozen C4 law on the joint union.

To preserve the source in the sham, its incoming bath drive is common replay:
first evolve a source-free reference bath from the same bath initial state, then
replay that bath trajectory to the source in every condition. The actual bath
remains dynamic and receives the source's outgoing channel in INTACT. The replay
is an explicitly declared exogenous boundary condition, not a coarse predictor
or a hidden answer. Its construction and storage are charged and recorded. The
controlled apparatus tests a conditional source effect; it does not establish
unconstrained reciprocal source/bath evolution.

| Paired condition | Source internal dynamics | Source input | Source→actual bath |
|---|---|---|---|
| INTACT | Full two-way C4 terms | Common reference-bath replay | Enabled |
| NO-R | Internal and incoming J=0 and K=0 (closure ablated; attraction/repulsion retained) | Same replay | Enabled with resulting non-resonant constituents |
| NO-BACKREACTION | Identical to INTACT | Same replay | Zero outgoing geometry and phase contribution |

Do not remove source nodes from neighbor selection to implement the sham. Compute
the complete outgoing channel, then multiply its contributions by zero; topology
and denominators stay those of that channel before treatment masking. Each
condition's evolving bath can change external neighbors naturally. Verify that
INTACT and sham source states agree within numerical tolerance, that the sham's
outgoing contribution is exactly zero, and that NO-R removes the internal closure.
If NO-R nevertheless qualifies as a resonator, record control failure; never
select a more convenient ablation after final outcomes.

The directed adapter requires independent reference, zero-mask/identity, permutation,
translation/rotation, dt-halving and replay interpolation checks before causal claims.
No old C4 equivalence receipt qualifies the changed joint law.

## 4. Arm B timeline, background descriptor and later formation

Each turn uses the same procedure. Base time scale C=1; inherited measured C may
normalize a later turn only through the ledger's one fixed rule. In B the proposed
sources are the same primitive-scale cohort, so C=1 for both turns. Two background
turns need not be two increasing-size hierarchy transitions.

1. Save B_before at t=0. Run the source-free reference and three conditions for
   100 time units. Apply the same C4 membership/shape/lock/signature/recovery
   criteria at t=100 (window 30, frames every 1). Evaluate source G→M and M→G
   paired interventions/complete internal ablations in separate forks; local
   closure must qualify independently of a later background difference.
2. Save B_after_intact, B_after_no_R and B_after_no_backreaction at t=100. Sources
   continue evolving; no promotion changes their law, position or bath coupling.
3. Measure the fixed background descriptor on snapshot forks. Probe bath elements
   by initial bath ID ranks 0 and 12 (IDs independently randomized before simulation).
   At each port, apply a .5-rad phase kick. Also apply a rigid .2 L_B push to the
   same two ports along the initial bath's first-to-second port axis; a zero axis
   is an invalid probe, not a replacement choice. Use all other bath elements as
   receivers, exclude source elements. Record paired unperturbed responses over
   10 time units every .1. Probe forks never change the later-assay initial state.
4. Expose the same four unformed 24-element candidate states to each after-background,
   one candidate per independent **snapshot fork**. Candidate geometry/phases/rates
   use the source rule, with centre fixed at (2,0), without translating toward any
   realized group. Before and control backgrounds receive the identical candidates
   as a diagnostic. No already-formed units are assembled. Run 100 time units and
   detect using the same criteria/closure assays in every condition. Existing R0
   supplies the same recorded drive in every matched assay fork, so a candidate
   contrast travels through the inherited bath, not a differing direct R0 input.
   Each candidate receives a candidate-free reference-bath replay computed from
   that condition's inherited bath and common R0 drive, using the same apparatus
   as the initial source. These inputs may differ across conditions **only through
   the inherited bath**, which is the intended mediator. Candidate→actual bath
   remains live; references and old R0 replay are charged. Keep the reference
   trajectory so turn 2 uses exactly episode 0's inputs rather than a new drive.
5. Candidate episode 0 alone is the predefined R1 for turn 2, if it qualifies.
   Other successful candidates cannot replace it. Retain its INTACT inherited bath
   snapshot at introduction and run the same INTACT/NO-R/sham operation, with R0's
   drive common across branches and episode 0's stored candidate-free reference
   from that inherited bath. The R1 INTACT branch reproduces episode 0; the turn is not a
   newly assembled fixture. Measure B1_before and B2_after and expose four fresh
   identical later candidate states by the same assay. All full bath/source
   elements remain active, including replayed R0 state.

The descriptor has two preregistered scalars, with raw response arrays retained:

`b_phase = RMS wrapped bath phase response`, averaged across the two kick ports;
`b_position = RMS bath displacement / L_B_before`, averaged across the two push ports.
The RMS averages receiver elements and recorded times. L_B_before is the bath's
radius of gyration at turn start, held fixed across all branches of that turn.
B_before uses the same probes. Thus B is defined independently of formation outcomes.
The descriptor deliberately samples response, not a claim about all background states.

Primary signed background contrasts for each control q are
`D_phase(q) = (b_phase_after_intact - b_phase_before) -
              (b_phase_after_q - b_phase_before)`.
Position response is a declared diagnostic with its own coverage. The proposed
direction is **increased phase susceptibility**; practical margin .05 rad against
both controls. The shared before term cancels but remains reported. Reduced response
is an honest failure of this directional model prediction, not of universal RRG.

Primary changed-possibility endpoint is the fraction of the four later candidate
episodes forming a persistent G↔M unit, with the exact same criterion in every
condition. World contrast `D_form(q) = fraction_intact - fraction_q`; proposed
direction is improvement ≥.10. Save lifetime/recovery and reachable group sizes
as diagnostics; they cannot substitute for the primary formation endpoint.

Only candidates entirely attributable to the new cohort count for the registered
later-formation endpoint. Mixed bath/candidate units, coexistence and missed source
formation remain visible. If the law instead produces mixed structures, redesign
requires a new prospective protocol, not post-hoc membership relabeling.

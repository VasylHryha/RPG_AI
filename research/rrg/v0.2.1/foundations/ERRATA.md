# Compatibility notes for unchanged foundation snapshots

**2 October 2026 · accompanies RRG v0.2.1**

Files 01–03 in this folder are preserved byte-for-byte from the retrieved foundation snapshots. They are historical sources of terminology, not a newly recertified evidence publication. This note records known compatibility issues without silently rewriting them.

| Location | Issue | Current treatment |
|---|---|---|
| 01–03: geometry and mode definitions | Core definitions need continuity | Retain \(R=(G,M)\) and full mode structure, not scalar frequency alone. |
| 02 §23 and §24; 03 §40 | A proof-first model program and qualitative confidence labels are presented as project direction | Current direction is publication/evidence-first; model building remains optional. Qualitative self-assessment is not validation. |
| 02 §23; 03 recursive-closure sections | Same-family mathematical closure is stronger than the author’s abstract recursive proposal | Retain as an optional stronger conjecture, not a publication prerequisite or proven identity. |
| 03 §§7 and related adaptive-network examples | Compatibility is inserted into an edge-update law | It is an explicit model assumption, not a derivation that compatible structures necessarily reinforce one another. |
| 03 §§27–28, 35–39 | Action, potential energy, stationary candidates, forces and frequency spectra are compressed into one notation | Specify the dynamical/variational setting. A general action cannot simply be treated as a static potential. Stability needs a separate dynamical test. See audited 04 §24. |
| 03 §39 | A display equation is missing its closing `\]` after the displayed force expression | Formatting defect retained in the immutable snapshot; insert the delimiter before “defines the restoring/driving interaction” in any newly typeset derivative edition. |
| 02 cosmological chronology and citations; 03 recent fundamental-physics references | Not all source claims were freshly verified in this audit | Do not present these as part of the 22 audited case cards. A separate review is needed before reusing their detailed claims in a current public evidence section. |
| Original README | Reading order stops at 03 | The new root README is the current index; the original is retained under `archive/`. |

The numerical source-model branch is corrected in current 05. No claim is made that these foundation snapshots, or their sources, were changed in the user’s Library or Project.

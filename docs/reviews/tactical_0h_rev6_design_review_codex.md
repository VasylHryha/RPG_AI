1. **CRITICAL — The claimed geometric exclusion of direct input at the output is false.**

   **Evidence:** draft lines 121–123 say the port cannot receive direct drive because sensors are at radius 4 and drive reach is strictly below 3. The port is a **disk**, r < 2, not the point r = 0. With a sensor at q = (4, 0), an output element at x = (1.5, 0) has port radius 1.5 and sensor distance 2.5: both kernels are nonzero. The disks overlap because 4 < 3 + 2. Only r ≤ 1 is excluded from every sensor's direct reach. Base section 3 and `geomind/c4_model.py:78` use strict cutoffs. An origin birth is initially undriven, but its subsequent motion or a later spiral point need not remain so.

   **Fix:** select and register a genuinely separated layout. Keeping the sensor ring and drive radius requires output radius **at most 1**, with a strict cutoff; keeping the output radius 2 requires sensor radius **at least 5**. A third option is an explicit phase-drive mask for output members, whose membership changes and geometric drive must then be declared. Recompute bridge distances, placement constraints and readout weights for the chosen layout. Retain a frame-level diagnostic of direct-drive exposure of every contributing output member. Delete the assertion that distance from the origin alone proves a grown path or prevents an echo. Earlier reviews, including mine, missed this disk-intersection check.

4. **HIGH — Site attraction is a new, dimensionally incomplete law and can destroy output occupancy.**

   **Evidence:** draft lines 108–114 call the additional term “no new law.” C4 averages attraction **and repulsion over element neighbors**. Sites never repel, so an isolated particle can collapse onto a site; site attraction can pull an output/bridge toward the sensor and **out of the port**. It vanishes outside sensor reach and while input is hidden. No on-paper argument establishes global confinement or preservation of C4 dynamics.

   **Fix:** mark this as a new hypothesis in the claim ledger and implement it only in new adapters/files. Define a dimensionless strength, for example k_s/k_ref with an explicit fixed rad/s reference, and give every motion coefficient's units and time conversion. Specify finite behavior at zero distance, the complete denominator, cutoff handling and evaluation at all RK4 stages with stage-correct site phases. Using old numerical A/J values does not transfer accepted C4 evidence to this law.

## Recommended definition of connection and stability — questions 1 and revised B

### A connection is an identifiable causal path with a contract

Write the assembly as a directed graph of frozen or declared trainable components. For an edge e from piece i to piece j:

`z_i = f_i(x_i, h_i); m_e = c_e(z_i, allowed_context); a_j = f_j(x_j, m_e, h_j)`.

Declare the message schema, semantic meaning, units/frame, entity identity, ordering, masks, valid ranges, update time, lifetime, error handling and allowed context. Declare who owns hidden state and when it resets. State which paths exist besides this edge. A schema-conforming output is not automatically an accurate or useful output.

In the actual two-piece graph, AIM emits an enemy slot; a **gather operation** selects that enemy's relative position; MOVE receives that position and own preferred range. The gather and feature scaling are part of the connector. AIM's output type is not literally identical to MOVE's input type. Evidence: `zd_models.py:55–56,229–237` and `tactics.py:364–373`. Register target identity/mask and one observation snapshot so a slot cannot refer to a different/dead enemy after reordering or a time update. Attacks and movement must use the same decoded target identity.

A declared connection exists structurally when this path is implemented. Its causal use is tested by changing only its message, holding component weights, observation and other paths fixed, and observing a downstream response on predeclared message-sensitive states. It is useful when an intact path improves held-out task performance over a registered cut/default/shuffled path. Absence of such an effect can mean an unused path or a redundant path; report which assay was sensitive enough to distinguish them. Do not equate topological presence, causal use, usefulness and robustness.

Contract plus compatibility testing is therefore a good starting definition. “Measured stability” is a qualification of a particular assembly within a stated envelope, not a prerequisite for saying an edge exists.

### Gain over ablation: retain it, name precisely what it measures

Let `W_s(P)` be the mean episode score of policy P in seed block s: win=1, draw=0.5, loss=0. Equal weight the two frozen opponents. Also report actual win/draw/timeout shares; the existing score treats timeouts as draws (`tactics.py:112–115`). Let R be rush and T the full scripted teacher for this exact task revision. Define:

`D = median_s[W_s(T) - W_s(R)]`.

For any registered paired comparison, define normalized gain:

`Q(P, B) = median_s[W_s(P) - W_s(B)] / D`.

This is a ratio of paired medians, not a median of seedwise ratios or a difference of separately reported medians. Keep one D for every rung, swap and perturbation in that task revision. Joint seed resampling of numerator and denominator can describe the ratio; the primary normalized predicate uses the conservative confidence-bound rule below rather than dropping undefined bootstrap ratios. The reference quality `q(P)=Q(P,R)` gives R=0 and T=1; outcomes below 0 or above 1 are valid. T is a reference ceiling, not an optimal-policy bound. Never normalize fidelity by win headroom. Because medians are nonlinear, `q(P)−q(B)` need not equal `Q(P,B)`; compute each paired contrast directly.

Let P(S) activate learned pieces in subset S and use fixed defaults in every other slot; P(empty) must reproduce R. Freeze active piece weights across ablations and ladder rungs. For k pieces, evaluate all `2^k` subsets, at most 16 for k=4. **Defaulting a learned piece does not necessarily remove the graph's connection**: a scripted/default MOVE can still consume AIM's selected target. Specify each default's inputs/routing and keep its behavior fixed across subsets.

For a fixed finite alternative set B, define `Delta_b = median_s[W_s(P)−W_s(B_b)]` and `G_min = min_b Delta_b`; normalized worst fixed-alternative gain is `G_min/D`. This is the declared median-contrast estimand: improvement against every fixed alternative, not a difference of unpaired medians or an unimplementable per-seed winner. Report every Delta_b and, separately, a development-selected deployable comparator. Recompute the minimum of the **aggregate contrasts** in statistical resamples. A seedwise switching-envelope diagnostic is optional and must not determine the main verdict.

Make these endpoint families distinct:

1. **Owner's single-piece/default alternatives:** for k>=2, B contains R and each P({i}), with the fixed registered default variants. Use G_min to test improvement against them all. For k=1, report utility over R; do not call it inter-piece connection quality.
2. **Indispensable contribution:** B contains every fixed P(K minus {i})/default variant. This tests the full assembly against each one-piece-removed policy. The single-piece family can pass when the third piece contributes nothing; this family prevents that reading.
3. **Fixed ladder contribution:** predeclare `K_j=(AIM, MOVE, ABILITY[, fourth])` prefixes and compare P(K_j) with P(K_{j-1}), including first-piece utility over R. Positive gains support this order, not every possible order. Report the other subsets so adverse interactions remain visible. A failed prefix does not rule out a working full assembly; it refutes/limits the specified monotone ladder claim.
4. **Signal contribution:** B contains predeclared edge cuts/default/shuffle interventions with the **same active pieces**. Freeze all other paths and isolate the nominated wire from the context it is allowed to read. This tests added value of communicated information with the same receiver. An off-manifold cut shows dependence/vulnerability; for a useful-signal claim also compare a meaningful default signal from the same permitted observation, and do not rely solely on random garbage.

Defaults cannot include teacher labels or the upstream prediction through another path. Modules with broader observation access are stronger conventional controls, but they are not identical-receiver signal cuts. These are separate comparisons. No primary comparator is selected from final scores after inspection.

This answers the new question directly: **yes**, performance-gain-over-ablation is falsifiable and valuable, but its claim is conditional on the ablation family. A simple analytical counterexample explains the restriction: suppose each independent action head adds 0.04 to a reward and no head consumes another's output. Every ladder step improves, although there is no causal inter-piece edge. Module ablations alone cannot establish connection value. Conversely, a useful redundant connection need not pass every leave-one-out necessity test. The proposed “every added piece helps” bar defines an indispensable ladder; it is not a universal definition of every proper modular system.

### Minimum function, proper structure, stability

The minimum runnable structure is a total, legal controller on its declared input domain: finite valid actions, living target or specified terminal/no-target behavior, correct routing, bounded execution, state reset and no silent bypass. That establishes executable function. Task usefulness needs an additional performance bar; proximity to the teacher is a higher fidelity standard, not the minimum meaning of functioning.

For this experiment, distinguish:

- **Functions usefully:** legal execution plus a positive held-out advantage over rush; proposed practical bar below is 0.03 raw win-score points.
- **High-fidelity working assembly:** functions, and is no more than 0.05 below T on win score and 0.05 below T on joint-action fidelity. The latter means at least approximately 95% teacher-action fidelity, a different requirement from 0.03 noninferiority to an already imperfect learned assembly.
- **Good indispensable ladder:** functions, every registered addition clears its margin, and each learned piece is necessary in the full assembly. Use the signal-contribution endpoint before attributing a gain to an edge.
- **Stable within the tested envelope:** a usefully functioning assembly retains quality in the lower seed tail and across the registered signal disturbances. Stability does not additionally require every piece or edge to be indispensable. It may have a sharp failure boundary; specify that boundary rather than assuming smoothness everywhere.

The most informative stability evidence is **closed-loop, quality-conditioned perturbation response plus a lower-tail performance check**. Seed spread measures repeatability of training/data/evaluation, not connection mechanics. Swap spread mixes component competence and compatibility. Report it, but do not require all schema-conforming implementations—including intentional failures—to lie within 0.03. Prequalify the interchangeable family and test each swap's noninferiority. A low spread around poor performance establishes nothing useful.

The old gap is a diagnostic, not a certificate. `zd_run.py:74–87` subtracts target success times MOVE success when forced to the teacher's target from joint success under the model's actual target. These are different target distributions. In contrast, `joint_action` already reports conditional MOVE success among admissible selections, for which multiplying by target success reproduces joint success by definition. Neither a near-zero difference nor that identity proves lossless causal wiring. Error correlation, tied targets and selection-induced distribution shifts remain possible.

### A. Replacement and baseline adequacy

Use three distinct conventional comparators:

1. **Whole flat F\*:** development-selected flat policy with strong capacity/depth and loss/head tuning. Output-head extraction from this same trained checkpoint tests whether an action channel can be replaced without retraining the rest. It is a useful diagnostic of this exact conventional policy, not a claim about all normal AI.
2. **Conventional conditional policy J:** a jointly trained target-conditioned policy, retaining S1 and allowing a stronger conventional recipe. Its real AIM and MOVE branches satisfy the registered connector contract and can be swapped without pretending an unconditional head accepts a target. This shares the graph; that is the correct control for claims about replaceability versus separately taught modules.
3. **Standalone conventional modules:** separately trained on the slot task, using a competitive ordinary architecture and the same permitted input/supervision budget. These test whether the proposed pieces outperform ordinary modules, rather than giving only the proposed system a modular API. Report a matched-input comparison and any richer-input comparator separately. Off-the-shelf game policies are optional only after a validated action/observation adapter and task competence check; their provenance alone does not make them fair or strong.

Development F\* selection: maximize mean closed-loop score on both opponents, with a fixed tie-break by a macro average of **disjoint** hold, approach and back-off fidelity strata, then lower cost. The existing “moving” overlaps back-off, so it is not a three-way disjoint macro partition. Give each family a bounded frozen search allowance; useful candidates include widths 16/32/64/128, depths 2/3/4 and tuned duration/regularization. Allow continuous, discrete and mixture movement heads rather than limiting the family to single-vector squared-error regression on multimodal labels. This is a proposed candidate set, not an obligatory exhaustive Cartesian search. A per-target movement head conditioned on selection is a **structured conventional policy**, not an unstructured flat model; name that architecture change honestly. Report total search cost, boundary optima and search limits; no automatic final-result retuning.

Baseline gate for a proposed conventional replacement host/whole-policy comparator: L(median[W(host)−W(R)])>0.03 overall, and L of each opponent contrast >0. A weak or uncertain F\* blocks a general advantage/failure claim against that flat family, while a competent J can qualify the ordinary-policy replacement claim. Learned-for-oracle replacement and independent assembly/edge attribution remain assessable without adequate F\*.

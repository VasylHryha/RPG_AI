C1 starts from a saved exact state compiled from public constraints. The candidate keeps its state in memory and applies additive deltas under a 100,000-operation cap that covers every in-memory step. New nodes are placed, and existing coordinate frames connected, using only added public constraints; only the smaller frame translates. Relaxation follows the C0 residual law and step, and a local certificate checks every node whose force may have changed. Refusals undo every change from a journal. A separately capped CG fallback is a distinct arm. Export and load are global, timed separately, and validated by the accepted C0 code. Coordinates stay in the export gauge, with each anchor at exactly 0. Nineteen focused checks cover references, exact operation charging, mid-relaxation rollback of every structure, local-certificate soundness against global validation (including large coordinates, re-anchoring and a relaxation frontier), bit-exact degree upkeep, overflow and oversized invalid input, uncharged-work detection, the incremental compiled baseline, the registered endpoint rules, chained, cyclic and duplicate-copy updates, migration of real R002/R003 artifacts, tolerances, overflow, tiny weights, the fallback cap, evaluator negative controls and evidence qualification.
